# ENZO. Digital Studio

An immersive, responsive portfolio website for ENZO. Digital Studio.

## Features
- Responsive dark-purple visual identity
- GSAP scroll and entrance animations
- Three.js interactive 3D hero object
- Accessible mobile navigation
- Reduced-motion support
- Email contact link

## Run locally
Open `index.html` in a modern browser with an internet connection. External fonts and animation/3D libraries load from CDNs.

## Deploy with GitHub Pages
In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Project note
The portfolio entries are fictional concept studies for demonstration purposes. They are not commissioned client projects.
